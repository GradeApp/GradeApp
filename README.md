GRADE — Genuine Reward for Academic Development — is developing a program connecting verified final semester grades with education opportunities after high school.

**[GRADE website](https://grade.global/) · [Explore the demo](https://thegrade.app/) · [Project overview](https://github.com/GradeApp/GRADE)**

The pilot model is **1 GRADE = $100 tuition discount**, used after high school graduation. Partner terms determine discount availability and the portion of tuition covered. The project is in development; real discounts are not yet guaranteed.

The demo uses fictional data and programs. Planned capabilities include verified academic rewards, an academic profile, forecasts and access to future partner opportunities. See the [project overview](https://github.com/GradeApp/GRADE) for the reward table and planned scope.

For pilot participation and partnerships, [contact the GRADE team](https://grade.global/contact.html).
